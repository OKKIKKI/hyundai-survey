# OKIKI 차량 이용 경험 설문

차량 이동 중 어떤 경험을 중요하게 생각하는지, 어떤 디지털 기능을 사용하는지, 차량용 앱에 어떤 기능을 원하는지 알아보기 위해 진행한 사용자 조사입니다. 이 저장소에는 조사에 사용한 설문 화면과 운영 당시의 응답 처리 코드가 담겨 있습니다.

**[설문 미리보기](https://hyundai-survey.vercel.app/survey.html)**

조사는 종료되었습니다. 미리보기에서는 실제 문항과 선택지를 살펴보고, 답변에 따라 후속 문항이 어떻게 달라지는지 확인할 수 있습니다. 신규 응답 접수는 마감되었습니다.

## 조사 개요

- **조사 대상** — 차량 이용 경험이 있는 운전자와 동승자
- **조사 기간** — 2026.11.04 17:00 ~ 2026.11.06 12:00 (한국 시간)
- **조사 방식** — 온라인 설문으로 단일 선택, 복수 선택, 주관식 응답을 수집했습니다. 일부 후속 문항은 앞선 답변에 따라 표시됩니다.

## 설문 구성

- 차량 이용 목적, 동승자, 연령대와 대표 이용 상황
- 이동 중 중요하게 생각하는 경험과 원하는 차량용 앱 기능
- 차량 내 디지털 기능 사용 방식과 시스템 선택 이유
- Pleos Connect 사용 경험, 조건부 인터뷰 참여 의향, 경품 추첨 안내

이용 목적과 동승자를 선택하면 후속 문항의 대표 선택지가 달라집니다. 디지털 기능 이용 방식에 따라 시스템 선택 이유가 표시되고, Pleos Connect 사용 경험이 있는 경우 인터뷰 의향 문항이 열립니다.

## 로컬 미리보기

저장소 루트에서 Python 3로 정적 파일을 제공한 뒤 브라우저에서 [로컬 설문 화면](http://127.0.0.1:5173/survey.html)을 엽니다. 설문 미리보기에는 별도의 DB 설정이 필요하지 않습니다.

```bash
python -m http.server 5173 --bind 127.0.0.1 --directory public
```

## 운영 당시 구현

조사 기간에는 서버에서 제출을 검증하고 응답을 저장했습니다. 같은 제출의 재시도는 기존 저장 결과로 처리했고, 브라우저에서 제출 완료 상태를 다시 확인할 수 있었습니다. 관리자 화면에서는 응답과 문항별 집계를 조회하고 CSV를 내려받을 수 있었습니다. 경품 신청 연락처는 설문 답변과 별도 테이블에 저장했습니다.

| 경로 | 역할 |
| --- | --- |
| `public/survey.html`, `public/site.css` | 설문 시작 화면, 문항과 조건부 분기 |
| `public/car.js` | Three.js와 GLB 차량 모델을 사용한 시작 화면 |
| `app/api/[...path]/route.ts`, `lib/survey-api.ts` | 설문 API, 응답 처리 및 관리자 조회 |
| `public/admin.html`, `public/admin.js` | 관리자 조회 및 CSV 내보내기 화면 |
| `supabase/migrations/`, `drizzle/` | Vercel 운영 환경의 Supabase 스키마와 초기 Cloudflare D1 스키마 |

공개 미리보기는 Vercel에서 제공하며, 현재 신규 제출 API는 HTTP `410 Gone`을 반환합니다.
